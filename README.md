# 多设备模拟器上位机

这是一个基于 Python + PyQt5 的多设备模拟上位机，用来模拟多个子设备的状态，并通过 GUI 或 TCP 方式与外部网关交互。

## 当前功能

- 设备管理：新增、删除、遍历、查找设备
- 单设备状态：温度、湿度、报警、在线/失联、最后心跳
- 自动模拟：定时心跳、状态随机变化、失联超时判断
- GUI 操作：
  - 设备列表
  - 设备详情编辑
  - 单设备操作
  - 批量设置温度/湿度
  - 全部报警/全部消警/全部失联/全部恢复
  - 日志窗口
- TCP 通信：
  - 发送 JSONL 格式数据帧
  - 接收网关命令并更新设备状态
- 自动化验证：
  - 控制台演示
  - GUI 冒烟测试
  - TCP 回环冒烟测试

```powershell

```

```powershell

```

## GUI 使用步骤

1. 启动程序后，会看到主窗口和默认的 10 台设备。
2. 在左侧列表选择设备，右侧可以查看和修改该设备的温度、湿度、在线状态和报警状态。
3. 点击“应用修改”后，设备状态会立即更新，日志窗口会记录操作。
4. 使用“触发报警”“消除报警”“模拟失联”“恢复在线”可以测试单设备状态流转。
5. 多选设备后，可以使用“批量设置温度”“批量设置湿度”对多个设备同时生效。
6. 使用“全部报警”“全部消警”“全部失联”“全部恢复”可以做全局控制。
7. 如果填写了网关地址和端口并点击连接，设备动作会按 JSONL 数据帧发送给网关。

## 验收建议

- 先跑 `--smoke-test`，确认模型和 GUI 批量逻辑没问题。
- 再跑 `--tcp-smoke-test`，确认本地 TCP 发包和收包没问题。
- 最后启动 GUI，手工检查列表、详情、批量控制和日志。

## Windows 说明

程序会自动尝试配置 PyQt5 的平台插件路径。如果本机 Qt 环境有特殊安装方式，启动时仍出现插件错误，可以手动检查虚拟环境下的：

```text
D:\计算机技术\.venv\Lib\site-packages\PyQt5\Qt5\plugins\platforms
```
